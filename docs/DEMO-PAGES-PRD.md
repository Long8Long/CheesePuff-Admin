# Demo页面展示需求文档 (PRD)

## 📋 项目概述

**目标**: 在CheesePuff-Admin信息管理系统中创建4个Demo展示页面，用于系统功能预览和演示。

**核心原则**:
- **数据统计为核心**: 重点展示系统各维度的数据指标
- **财务为次要**: 财务统计简化处理，作为辅助功能
- 使用静态数据，不调用后端接口
- 遵循项目现有的Feature-Based Architecture
- 使用Shadcn UI组件库
- 简洁明了的功能展示
- 纯前端Mock数据

## 🎯 页面清单（按优先级排序）

### 1. 数据统计 (Statistics) ⭐⭐⭐ 核心页面
**路径**: `/statistics`
**用途**: 展示系统核心业务数据指标，是多维度数据的总览页面

**功能模块**:

#### A. 核心业务指标卡片区（8个卡片）
**第一行 - 实体数量统计**:
1. **猫咪总数** - 系统中所有猫咪数量
   - 显示：总数、本月新增、状态分布
   - 图标：猫咪图标
   
2. **店铺数量** - 旗下门店数量
   - 显示：总数、营业中、筹备中
   - 图标：店铺图标
   
3. **品种数量** - 猫咪品种数
   - 显示：总数、常见品种TOP3
   - 图标：分类图标
   
4. **会员总数** - 注册会员数量
   - 显示：总数、本月新增、活跃会员
   - 图标：用户图标

**第二行 - 运营数据统计**:
5. **总收入** - 累计收入金额
   - 显示：总金额、较上月增长率、本月收入
   - 图标：收入图标
   
6. **本月订单** - 当月订单数量
   - 显示：订单数、完成率、平均金额
   - 图标：订单图标
   
7. **活跃猫咪数** - 当前可在店的猫咪
   - 显示：数量、占比、健康状态
   - 图标：状态图标
   
8. **待处理事项** - 待办任务数
   - 显示：数量、紧急任务、已完成
   - 图标：提醒图标

#### B. 数据分布图表区（2x2网格布局）
1. **猫咪状态分布图** (饼图)
   - 分类：在店/休假/医疗/已退役
   - 展示各状态占比和数量
   
2. **品种分布TOP5** (横向柱状图)
   - 展示数量最多的5个品种
   - 显示品种名和数量
   
3. **会员增长趋势** (折线图，12个月)
   - 展示近一年会员增长曲线
   - 标注关键节点（促销活动等）
   
4. **店铺业绩对比** (雷达图或柱状图)
   - 展示各店铺的关键指标对比
   - 维度：收入、订单数、会员增长、猫咪数

#### C. 页面布局优化
**一页内展示原则**：
- 所有卡片、图表在一屏内展示，无需滚动即可查看全貌
- 紧凑布局，避免内容过多
- 重点展示KPI指标和数据趋势，详细数据表格由其他专门页面负责

**布局设计**：
```
┌─────────────────────────────────────────────┐
│  标题：数据统计                                │
├─────────────────────────────────────────────┤
│  [猫咪总数] [店铺数量] [品种数量] [会员总数]     │
│  [总收入]   [本月订单] [活跃猫咪] [待处理事项]  │
├─────────────────────────────────────────────┤
│  [猫咪状态饼图]     [品种分布柱状图]           │
│  [会员增长折线图]   [店铺业绩对比图]           │
└─────────────────────────────────────────────┘
```

**说明**：
- 第一行：8个KPI指标卡片（2行4列）
- 第二行：4个数据分布图表（2行2列）
- 所有内容紧凑排列，一屏展示完毕
- 详细数据查询请访问：猫咪管理、会员管理、店铺管理等专门页面

### 2. 财务统计 (Financial) ⭐⭐ 次要功能
**路径**: `/financial`
**用途**: 简化的财务数据展示，作为辅助参考

**功能模块**:
- **财务概览卡片**（4个）
  - 今日收入
  - 本月收入
  - 本月支出
  - 净利润
  
- **收支趋势图**（单张折线图）
  - 近6个月收支对比
  - 简洁的双线展示
  
- **最近交易记录**（简化表格）
  - 字段：类型、描述、金额、日期
  - 数据：8-10条示例记录
  - 类型：收入/支出

**简化说明**:
- 仅展示核心财务指标
- 不做复杂的财务分析
- 数据量控制在最小范围
- 主要是为了演示系统有能力展示财务数据

### 3. 库存管理 (Inventory) ⭐⭐⭐ 核心业务功能
**路径**: `/inventory`
**用途**: 展示商品库存管理功能

**功能模块**:
- **库存概览卡片**（4个）
  - 商品总数
  - 低库存商品数（< 10件）
  - 本月入库数量
  - 本月出库数量
  
- **低库存预警列表**（Card + Table）
  - 显示库存不足的商品
  - 字段：商品名称、当前库存、预警阈值、状态
  - 状态标签：正常/预警/紧急
  - 数据：5-8条预警记录
  
- **库存明细表格**
  - 字段：商品名称、分类、当前库存、单价、总价值、状态、操作
  - 操作按钮：入库、出库、编辑
  - 数据：12-15条示例记录
  - 支持分类筛选和状态筛选

### 4. 育种管理 (Breeding) ⭐⭐⭐ 核心业务功能
**路径**: `/breeding`
**用途**: 展示猫咪育种记录和管理

**功能模块**:
- **育种概览卡片**（4个）
  - 在册种猫数
  - 本年新生幼猫数
  - 待产母猫数
  - 配种记录总数
  
- **育种流程看板**（3列布局）
  - **配种中**: 已配种等待确认
    - 卡片：母猫名、公猫名、配种日期、预计确认日期
    - 数量：3-5条记录
    
  - **妊娠中**: 确认怀孕待产
    - 卡片：母猫名、公猫名、配种日期、预产期、孕期状态
    - 数量：4-6条记录
    
  - **育儿期**: 已生产哺乳期
    - 卡片：母猫名、公猫名、生产日期、幼猫数、断奶日期
    - 数量：3-5条记录
    
- **育种记录表格**
  - 字段：母猫ID、公猫ID、配种日期、预产期、实产日期、幼猫数、状态、操作
  - 状态标签：配种中/妊娠中/已生产/已取消
  - 数据：12-15条示例记录
  - 支持状态筛选和日期排序

## 📊 页面优先级总结

| 页面 | 优先级 | 核心程度 | 数据量 | 复杂度 | 实现顺序 |
|------|--------|----------|--------|--------|----------|
| 数据统计 | ⭐⭐⭐ | 最高 | 中等（8卡片+4图表，一屏展示） | 中等（多种图表） | 3️⃣ |
| 库存管理 | ⭐⭐⭐ | 高 | 大（4卡片+预警+表格） | 简单 | 1️⃣ |
| 育种管理 | ⭐⭐⭐ | 高 | 大（4卡片+看板+表格） | 中等（看板布局） | 4️⃣ |
| 财务统计 | ⭐⭐ | 次要 | 小（4卡片+1图表+表格） | 简单 | 2️⃣ |

**实现建议**:
1. 先实现库存管理（简单，积累经验）
2. 再实现财务统计（简单，次要功能）
3. 然后攻克数据统计（复杂，核心页面，多种图表类型）
4. 最后实现育种管理（看板布局需要调试）

### 静态数据规范

**数据规模原则**:
- Demo页面以展示功能为主，数据量适中即可
- 表格数据：8-15条记录即可展示效果
- 卡片数据：真实合理的数值，符合业务逻辑
- 图表数据：6-12个数据点，足以展示趋势

**各页面数据详情**:

**1. 数据统计页面**（一屏展示，无表格）:
- KPI卡片：8个指标（猫咪、店铺、品种、会员、收入、订单、活跃猫、待办）
- 猫咪状态饼图：4-5个状态分类
- 品种分布图：TOP 5品种
- 会员增长图：12个月数据
- 店铺对比图：3-5个店铺，4个维度

**2. 财务统计页面**（数据量最小）:
- 财务卡片：4个指标（今日收入、本月收入、本月支出、净利润）
- 收支趋势图：6个月数据
- 交易记录表：8-10条记录

**3. 库存管理页面**:
- 库存卡片：4个指标（商品总数、低库存数、入库数、出库数）
- 低库存预警：5-8条记录
- 库存明细表：12-15条记录

**4. 育种管理页面**:
- 育种卡片：4个指标（种猫数、新生幼猫、待产母猫、配种记录）
- 育种看板：3列，每列3-6条记录，共10-15条
- 育种记录表：12-15条记录

**数据真实性要求**:
- 金额：使用合理的业务范围（元），如月收入5-20万
- 数量：符合实际规模，如会员数500-3000，猫咪数30-100
- 日期：使用近期时间范围（2025年1月-2026年6月）
- 状态：使用真实的业务状态值
- 分类：使用实际的业务分类（品种、商品分类等）
- 关联：表格数据与KPI数据保持一致（如总猫咪数 = 表格中猫咪数量）
